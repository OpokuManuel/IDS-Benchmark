# Data
`raw/UNSW_NB15_training-set.csv` (175,341 rows) and `raw/UNSW_NB15_testing-set.csv` (82,332 rows): the official UNSW-NB15
partition files. Verify with `cd raw && sha256sum -c SHA256SUMS`. Source and terms: https://research.unsw.edu.au/projects/unsw-nb15-dataset
Cite: Moustafa & Slay (2015), "UNSW-NB15: a comprehensive data set for network intrusion detection systems", MilCIS.
These copies were obtained from GitHub mirrors (UNSW's server was unreachable from the build environment); the data is not owned by this project.
